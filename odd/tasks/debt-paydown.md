# Debt paydown

## Goal
Pay down technical and operational debt before starting new product functionality, using small reviewable slices.

## Scope
- Reduce high-signal lint warnings.
- Address correctness/security follow-ups from risk review.
- Plan large component decomposition without mixing behavior changes.
- Audit offline write scope and cron scalability.
- Preserve pre-existing local changes unless explicitly included.

## Non-goals
- No new user-facing features.
- No global formatting sweep unless selected as its own slice.
- No broad component rewrites in the same slice as behavior fixes.
- No commits/pushes/PRs unless explicitly requested.

## Protected pre-existing local changes
- `.gitignore`
- `src/components/cards/cards-list.tsx`
- `.codegraph/`
